# VIPA Site

🌍 **No ar em:** [vipaapp.web.app](https://vipaapp.web.app)

Site oficial do VIPA – Transporte Escolar Inteligente, feito para apresentar o aplicativo a motoristas de van escolar e às famílias.

Feito em HTML, CSS e JavaScript puros, sem framework, seguindo a identidade visual do app. O `build.mjs` gera a versão publicada em `public/`, hospedada no Firebase Hosting.
